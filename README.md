# Autonomous Release Platform

## Overview

A CI/CD project built using Jenkins, Docker, GitHub, AWS EC2, and Python Flask.

## Technologies Used

* AWS EC2
* Jenkins
* Docker
* Git & GitHub
* Python Flask
* Linux

## Features

* Source code management using GitHub
* Jenkins Pipeline as Code
* Dockerized Flask application
* Automated build workflow
* Deployment on AWS EC2

## Architecture

GitHub → Jenkins → Docker → AWS EC2
